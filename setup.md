### EXERCISE 5

When I enter a website page, my browser sends a request to the server asking for the page. The server processes the request and sends back a response, which contains the information needed to display the page. The response also has a status code, such as 200 when the request is successful or 404 when the page cannot be found. HTTP is stateless, which means the server does not automatically remember previous requests from the same user.

### EXERCISE 6

A website can know that I am logged in by using a session or a cookie. When I log in, the website creates a session that remembers me while I move between pages. The browser can store a session ID in a cookie, which the website uses to recognize my login on later requests.
